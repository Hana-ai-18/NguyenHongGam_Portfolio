HOW TO PUBLISH (GitHub Pages)
1. Create a public repo named  Hana-ai-18.github.io  (GitHub username + .github.io).
2. Upload EVERYTHING in this folder (index.html, style.css, script.js, assets/) to the repo root.
3. Settings > Pages > Deploy from branch > main / root. Wait 1-2 minutes.
4. Your site: https://hana-ai-18.github.io

To change links: open index.html and search for "github.com/Hana-ai-18" (project buttons).
